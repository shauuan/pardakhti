# پرداختی (Pardakhti)

نرم‌افزار حقوق و دستمزد دسکتاپ (Flutter Windows) — آفلاین، یک‌کاربره، مطابق قانون کار ایران.

## وضعیت

**مرحله ۱:** اسکلت پروژه + Design System + کامپوننت‌ها + صفحات نمونه (بدون دیتابیس/محاسبه).

## اجرا

```bash
flutter pub get
flutter run -d windows
```

صفحات نمونه:
- `/` داشبورد با داده ساختگی (برچسب «نمونه»)
- `/showcase` نمایش کامپوننت‌ها

## تحلیل

```bash
flutter analyze
```
